# Brand reference

Not part of the site build — a reference for future visual changes.

## Palette (from polyforest.com style.css, measured 2026-09-24)

| Token | Value | Use |
|---|---|---|
| Canvas | `#191919` | page background |
| Gold | `#f0d554` | links, accents, highlights |
| Indigo | `#4e56e0` | secondary accent (spare) |
| Gray | `#646464` | muted text |
| Near-white | `#f5f2ea` | headings |

## Typeface

**Scope One** — the only font polyforest.com loads (Google Fonts). Self-hosted here via `@fontsource/scope-one` for headings and display; body text uses the system sans stack for readability and speed.

## Imagery

polyforest.com shows a low-poly night forest: faceted amber/gold trees on near-black, campfire glow. The favicon (low-poly pine) and social card (tree silhouettes over a fire glow) echo this without copying the site's assets.
